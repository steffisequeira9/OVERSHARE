# Overshare AI Advisor Proxy Server

## Architecture & Privacy Design
The Overshare AI Advisor is strictly **optional and off by default**. It assists users by explaining why a detected sensitive finding matters and offering clarifying questions.

### Strict Privacy Invariants
1. **Zero Raw Text / Images**: The mobile app **NEVER** sends image bytes, document pixels, file paths, or extracted raw text to the proxy or the LLM. Only abstract finding categories (e.g. `"Card Number"`, `"UPI ID"`), confidence scores (`0.95`), the selected `purpose`, and `audience` are transmitted.
2. **Advisory Only**: The advisor **cannot** create new findings, change rule engine decisions (`KEEP` / `HIDE` / `OPTIONAL`), or redact pixels.
3. **API Key Isolation**: The mobile client has no API keys. All credentials reside strictly in this backend proxy's environment variables.
4. **Resilient Silent Fallbacks**: If the proxy is offline, times out, or returns unexpected output, the client silently falls back to the deterministic reasons generated by the pure-Dart rule engine.

---

## Model Selection & Justification: `gemini-2.5-flash-lite`

Before choosing this model, we reviewed Google Gemini's official documentation (`models/gemini-2.5-flash-lite`):
- **Capabilities**: Native JSON Structured Outputs (`responseMimeType: "application/json"` with schema enforcement). Ensures the model strictly conforms to the advisory JSON schema with zero hallucinated keys.
- **Cost**: \$0.10 / 1M input tokens and \$0.40 / 1M output tokens (Free of charge in Google AI Studio tier). A typical advisory request is < 200 input tokens and produces ~100 output tokens, making each advisory call cost less than \$0.00006.
- **Latency**: Sub-second response time (~400-600ms), essential for interactive review before sharing.
- **Enterprise Privacy**: Under Google API paid tier and enterprise terms, customer prompt data and responses are **not** used to train Google models. Furthermore, because Overshare only transmits category labels and confidence, no sensitive PII ever reaches the model.

## Running the Proxy

```bash
cd server
npm install
cp .env.example .env
# Edit .env and supply GEMINI_API_KEY
npm start
```

The server runs at `http://localhost:3000` (or `http://10.0.2.2:3000` from the Android emulator).
If no `GEMINI_API_KEY` is provided, the server operates in local mock mode to facilitate offline development and unit tests.
